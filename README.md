# Инвентаризация 360° — демо интерфейса

Автономный визуальный макет с абстрактными заполнителями. В нём нет рабочих сведений, учётных записей, должностей, правил согласования, подключений к данным или сетевых операций приложения.

Доступны главная навигация, условные пространства и периоды, рабочая таблица, карточки, архив, аналитические вкладки и широкая сравнительная таблица, материалы, контакты, список событий и демонстрационные панели. Все значения пустые; схемы иллюстрируют только компоновку.

## Открыть

Скачайте файлы репозитория и откройте `index.html` в современном браузере. Интернет, установка зависимостей и сервер не нужны. Кнопки переключают макеты и открывают локальные окна. Ввод хранится только в памяти вкладки и исчезает при перезагрузке. Не вводите конфиденциальные сведения даже в демонстрационные поля.

## Разработка

Нужен Node.js 20 или новее. Сторонних зависимостей нет.

```bash
npm run build
npm test
npm start
```

Локальный адрес предпросмотра: `http://127.0.0.1:4177`. Сборка обновляет единственный готовый к показу файл `index.html` из файлов `src/`. Браузерные проверки описаны в `tests/browser.py` и используют установленный Playwright с Chromium.

Содержимое демо не сохраняется на диск браузером. Политика CSP запрещает сетевые соединения, внешние скрипты, внешние стили и отправку форм. Данные, вычисления, документооборот, авторизация и интеграции здесь не реализованы. Схемы не являются аналитическими результатами.

Репозиторий предназначен для приватного распространения. Сделать его публичным или разместить в интернете можно только после отдельного разрешения владельца. Доступ к репозиторию и доступ к скачанному HTML — разные вещи: скачанный файл получатель может скопировать и передать дальше.
