# Инвентаризация 360° — демо интерфейса

Автономное frontend-приложение для визуального показа интерфейса. Все обозначения абстрактные, значения показателей пустые, схемы иллюстрируют только компоновку. Рабочие сведения, персональные данные, учётные записи и реальные документы отсутствуют.

Готовый файл **[index.html](index.html)** содержит всё приложение. Его можно скачать и открыть в современном браузере без установки зависимостей и подключения к интернету.

## Доступные экраны

| Раздел | Что демонстрируется |
| --- | --- |
| Главная | Сетка карточек и единое меню разделов. |
| Инвентаризация | Условные пространства и периоды, таблица с пустыми полями, поиск, окно ввода, ручная форма и инструменты. |
| Списания | Список карточек и область просмотра с демонстрационными полями. |
| Акты проработок | Макет карточки, формы и таблицы. |
| Результаты | Внешний вид архива и просмотра выбранной карточки. |
| Разбор инвентаризации | Обзор, абстрактные схемы, горизонтальное сравнение периодов, скрытие дополнительных столбцов и табличный вид запаса. |
| Регламенты | Карточки материалов и пустое окно предпросмотра. |
| Объекты | Условные пространства без адресов и реквизитов. |
| Контакты и обратная связь | Абстрактные контактные карточки и локальное окно формы. |
| История изменений | Статичный макет таблицы событий. |
| Администрирование | Компоновка панелей и переключатели внешнего вида без модели пользователей и полномочий. |

Кнопки переключают экраны, открывают локальные диалоги и меняют вид макета. Они не выполняют операции с рабочими документами. Геометрия графиков задана для иллюстрации оформления и не представляет аналитические результаты.

## Техническая архитектура

- **HTML и CSS:** семантическая разметка, Grid/Flexbox, адаптивные медиазапросы, прокручиваемые таблицы и закреплённые заголовки.
- **JavaScript:** обычный браузерный JavaScript без фреймворков и сторонних библиотек. Клиентский код изолирован в функции; интерфейс формируется через DOM и шаблоны.
- **Навигация:** переключение локального состояния и повторное построение выбранного экрана. Серверного роутера нет. Действия обрабатываются через атрибуты `data-go`, `data-action` и `data-change`.
- **Состояние:** только память вкладки. Введённые значения не отправляются и не сохраняются приложением в постоянное хранилище. Перезагрузка сбрасывает состояние; отдельные поля макета могут очищаться при смене представления.
- **Графика:** встроенные SVG и CSS, системные шрифты. Внешние изображения, шрифты и библиотеки не загружаются.
- **Сервер:** для самого демо не нужен. Дополнительный сервер предпросмотра раздаёт только статический HTML на локальном адресе.

В приложении нет авторизации, базы данных, файлового хранилища, API, фоновой синхронизации, расчётов, экспорта документов или интеграций. Использование одинаковых названий экранов не означает наличия соответствующей бизнес-логики.

## Запуск и сборка

Для просмотра достаточно скачать `index.html` и открыть его в браузере. Если правила устройства запрещают открытие локальных HTML-файлов, используйте предпросмотр через локальный сервер.

Для разработки нужен **Node.js 20 или новее** с npm. Устанавливать пакеты не требуется.

```bash
npm run build
npm test
npm start
```

Предпросмотр доступен по адресу `http://127.0.0.1:4177`. Другой порт можно указать так:

```bash
npm start -- 4300
```

Сервер слушает только локальный интерфейс. Он обслуживает `/` и `/index.html`, принимает GET/HEAD, не публикует содержимое каталогов и не предоставляет операций записи. После новой сборки его нужно перезапустить: HTML считывается при старте.

Сборщик использует только стандартные модули Node.js. Он встраивает CSS и JavaScript из `src/` в HTML-оболочку, вычисляет SHA-256 для CSP и записывает корневой `index.html`. Минификации, карт исходников, сетевых загрузок и копирования внешних ресурсов нет. Готовый файл отслеживается Git, чтобы его можно было скачать отдельно.

Редактируйте файлы в `src/`, затем пересобирайте приложение. Ручная правка встроенного CSS или JavaScript в `index.html` нарушит соответствие исходникам и может привести к блокировке кода политикой CSP.

## Безопасность и проверки

Политика CSP встроена в HTML. По умолчанию источники запрещены; выполнение собственного скрипта и применение собственных стилей разрешены только по вычисленным хешам. `connect-src 'none'` блокирует сетевые соединения приложения, `form-action 'none'` запрещает отправку форм. Внешние скрипты, стили и шрифты не используются.

Клиент не использует браузерные API постоянного хранения, фоновые обработчики или сетевые вызовы. Исходники и готовая страница содержат только демонстрационные обозначения. Не вводите конфиденциальные сведения даже в эти поля.

`npm test` проверяет:

- точный разрешённый набор файлов, отсутствие символьных ссылок и бинарного содержимого;
- базовые шаблоны непрозрачных идентификаторов, секретных значений и внешних адресов;
- точное совпадение встроенных CSS/JavaScript с исходниками и корректность CSP-хешей;
- отсутствие сетевых вызовов, постоянного хранения и внешних ресурсов в клиенте;
- отсутствие сторонних зависимостей.

Проверка шаблонов не заменяет содержательную проверку новых материалов перед их добавлением. Нельзя добавлять рабочие справочники, документы, изображения с данными, персональные сведения, секреты или настройки подключений — в том числе в тесты и комментарии.

Для браузерных проверок нужны Python, Playwright и Chromium, установленные отдельно в среде проверки. Скрипт использует Chromium по пути `/usr/bin/chromium` и предпросмотр на стандартном порту. Запустите `npm start`, затем в другом терминале:

```bash
python3 tests/browser.py
```

Проверяются навигация, вкладки, поиск, таблицы, диалоги, локальные формы, сброс ввода, компоновка на разных размерах экрана, отсутствие внешних запросов и ошибок JavaScript/CSP. Автономный HTML также загружается в браузер с отключённой сетью. Прямая навигация по `file://` в этой проверке не используется: управляемые браузеры могут её запрещать. Эмуляция размеров окна не заменяет проверку на физических устройствах.

## Распространение и ограничения

Демо предназначено для показа внешнего вида, а не для учёта, анализа или документооборота. В нём нет сохранения, реальных файловых операций, пользователей, проверки полномочий или маршрутов согласования.

Репозиторий должен оставаться **Private** до отдельного разрешения владельца. Поле `private` в `package.json` защищает от случайной публикации пакета npm, но не управляет видимостью репозитория GitHub. Публикация сайта также требует отдельного решения.

Для показа можно передать только готовый `index.html`. Получатель сможет скопировать и переслать скачанный файл; приватность репозитория этого не предотвращает.
