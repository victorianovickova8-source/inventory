# Инвентаризация 360° — демо интерфейса

Автономное frontend-приложение для знакомства с интерфейсом «Инвентаризация 360°». Включает навигацию по разделам, адаптивные таблицы, карточки, вкладки и интерактивные диалоговые окна.

Готовый файл **[index.html](index.html)** содержит всё приложение. Его можно скачать и открыть в современном браузере без установки зависимостей и подключения к интернету.

## Экраны и возможности

| Раздел | Элементы интерфейса |
| --- | --- |
| Главная | Карточки разделов и единое меню навигации. |
| Инвентаризация | Выбор пространства и периода, рабочая таблица, поиск, окно ввода, ручная форма и инструменты. |
| Списания | Список карточек и область просмотра документа. |
| Акты проработок | Карточка, форма и таблица. |
| Результаты | Архив и просмотр выбранной карточки. |
| Разбор инвентаризации | Обзор, диаграммы, горизонтальное сравнение периодов, скрытие дополнительных столбцов и таблица запаса. |
| Регламенты | Карточки материалов и окно предпросмотра. |
| Объекты | Список пространств. |
| Контакты и обратная связь | Контактные карточки и форма обращения. |
| История изменений | Табличное представление событий. |
| Администрирование | Панели и переключатели представлений. |

Интерактивные элементы позволяют переключать экраны и вкладки, пользоваться поиском, открывать диалоги и знакомиться с вариантами оформления. Графики и таблицы демонстрируют компоновку интерфейса; учётные операции и аналитические расчёты в этой версии не реализованы.

## Технологии и архитектура

- **HTML и CSS:** Grid/Flexbox, адаптивные медиазапросы, прокручиваемые таблицы и закреплённые заголовки.
- **JavaScript:** браузерный JavaScript без фреймворков и сторонних библиотек. Экраны формируются через DOM и шаблоны.
- **Навигация:** обработчики атрибутов `data-go`, `data-action` и `data-change` переключают локальное состояние приложения.
- **Состояние:** хранится в памяти вкладки. Перезагрузка возвращает исходное представление; отдельные поля могут сбрасываться при переключении экрана.
- **Графика:** встроенные SVG и CSS, системные шрифты.
- **Сборка:** стандартные модули Node.js объединяют исходники в один HTML-файл.
- **Предпросмотр:** локальный статический сервер; серверная часть приложения не требуется.

## Запуск

Для просмотра откройте `index.html` в браузере. Если устройство ограничивает открытие локальных HTML-файлов, используйте сервер предпросмотра.

Для разработки нужен **Node.js 20 или новее** с npm. Установка пакетов не требуется.

```bash
npm start
```

Адрес предпросмотра: `http://127.0.0.1:4177`. Для выбора другого порта:

```bash
npm start -- 4300
```

Сервер слушает локальный интерфейс и обслуживает `/` и `/index.html`. После пересборки перезапустите его, чтобы загрузить обновлённую страницу.

## Разработка и сборка

Редактируйте файлы в `src/`, затем выполните:

```bash
npm run build
```

Сборщик встраивает CSS и JavaScript в HTML-оболочку, вычисляет SHA-256-хеши для политики CSP и обновляет корневой `index.html`. Этот файл включён в репозиторий и готов к просмотру. Политика CSP разрешает встроенные стили и скрипт по их хешам, поэтому изменения следует вносить в исходники с последующей сборкой.

## Проверки

Проверка структуры проекта, соответствия готового HTML исходникам и корректности CSP:

```bash
npm test
```

Для браузерных проверок нужны Python, Playwright и Chromium, установленные отдельно. Скрипт использует Chromium по пути `/usr/bin/chromium` и предпросмотр на стандартном порту. При запущенном `npm start` выполните в другом терминале:

```bash
python3 tests/browser.py
```

Браузерные проверки охватывают навигацию, вкладки, поиск, таблицы, диалоги, формы, сброс состояния, разные размеры экрана и ошибки JavaScript/CSP. Автономность проверяется загрузкой готового HTML при отключённой сети. Прямая навигация по `file://` и работа на физических устройствах в эту автоматическую проверку не входят.
